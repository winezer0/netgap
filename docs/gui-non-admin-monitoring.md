# GUI 普通用户启动监测修复

## 原因

默认启用自动断网，旧逻辑在启动整个监测任务前执行需要管理员权限的路由预检，普通用户被拒绝。前端未捕获启动异常，因此仍显示“未运行”且缺少错误提示。保存偏好也会重复执行同类预检。

## 当前处理

- 普通用户可直接启动监测，显示“运行中”，出口查询、地区匹配和告警照常执行。
- 自动断网设置保留；当前进程权限不足时自动删除和已保存断网任务的续作均暂停，不读写这些任务或恢复快照。
- 健康状态显示 `disconnectState=suspended`、`disconnectFailure=permission`；状态栏持续说明权限不足、仅告警、原设置保留。请求失败不会清除权限提示。
- 普通用户可保存地区、语言及其他偏好，也可保留或启用自动断网偏好；当前进程仍只能告警。
- 以具备权限的身份重新启动后，按保存的设置重新进行恢复存储预检。手动删除/恢复的权限检查仍保留；不同身份的恢复目录需自行核对。
- 其他启动错误会写入日志并在界面弹出具体原因。

该策略适用于 Windows 普通用户及 Linux/macOS 非 root 用户；Linux/macOS 管理员组成员身份不等同于有效 root。
