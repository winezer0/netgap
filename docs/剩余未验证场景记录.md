## 更新规则

- 完成场景后，将环境、步骤、结果和证据链接加入[已验证场景记录](已验证场景记录.md)，并从本表移除对应条目。
- 仅改善代码或通过模拟测试，不自动视为真实系统场景完成。
- 默认路由真实变更只在隔离测试环境进行；当前 WSL 不用于新增路由删除/恢复测试，也不操作 Windows 主机网络。
